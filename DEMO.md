# Demo script (under 3 minutes)

Live app: https://backstop-xi.vercel.app
(Convex mirror: https://festive-roadrunner-713.convex.site)

Recorded walkthrough (silent, ~45s):  
https://github.com/Demiladepy/backstop/releases/download/demo-video/backstop-hero-demo.webm

Positioning line, said once:

> Drafts and sends the appeals you approve — not legal or medical advice.

0:00–0:20 — Open the live site. **Enter private demo**. **Start a sample
case**. Keep defaults (deadline is already 14 days out). **Open case file** —
the fictional denial letter and EOB attach automatically.

0:20–1:00 — Stay on **Evidence** / **Appeal**. Watch parse → policy research →
cited draft appear live. Note both documents in Evidence. Call out unverified
claims if any paragraph lacks a source.

1:00–1:40 — Show citations (click [N] to flash the note). **Approve and send**.
Open **Email** and **Record** (sponsor-labeled timeline). Optionally **Simulate
fictional payer reply**, then use the follow-up banner → Appeal — still waits
for approval.

1:40–2:20 — **Watch** tab → **Run demo Watch beat**. Say: deadline armed,
public form filled with sample values, submit never clicked — no password or
card fields.

2:20–2:50 — Return to the case board. Close on one medical-denial case type,
human approval as the backstop.
